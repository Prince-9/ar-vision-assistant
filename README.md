# AR Vision Assistant

Unity mixed-reality assistant for Meta Quest with a Python gateway for image questions, OCR, speech, and conversation memory.

## Project layout

- Unity project: `Assets/`, `Packages/`, and `ProjectSettings/`
- Gateway backend: `Backend/`

Open this repository root in Unity 6. The gateway code and setup notes are in `Backend/README-chat.md`. Local model weights, Unity-generated folders, logs, and voice recordings are excluded from Git.
